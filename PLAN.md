# FURYCUBE G9 PRO HUB — цели и состояние

Требование пользователя: самостоятельный HUB, шестая кнопка работает сразу
независимо от OLED; картинки и виджеты на маленьком экране; публичный GitHub
с понятным README. Физическая кнопка должна работать после закрытия программы.
Макросы проверяются после обычной «0».

## Уточнение пользователя: работа по частям, физические проверки после сна

До возвращения пользователя продолжаются самостоятельная разработка, офлайн-
проверки, безопасное чтение устройства и публикация собственных исходников.
Не требуется держать пользователя у компьютера или ждать его для этих этапов.

**Обязательное условие: всё должно быть восстановимо.** Перепрошивка запрещена
до подтверждённого пути восстановления. Сохранённый официальный обновлятор и
копия таблицы кнопок не заменяют резервную копию текущей прошивки. Не предлагать
рискованную установку вместо подготовки восстановления.

## Подтверждено

- [x] Отдельный проект FURYCUBE-G9-PRO.
- [x] Прямое чтение таблицы кнопок и активного профиля через USB.
- [x] Одинаковая обычная «0» работает на колёсике, но не на кнопке-экране.
- [x] Экранная кнопка печатает «0» при зажатой правой кнопке.
- [x] Причина воспроизведена на оригинальных инструкциях прошивки: ожидание
      OLED-удержания откладывает press, затем release отменяет клавиатурную фазу.
- [x] Кандидат из двух байт отключает OLED-удержание без повышения debounce.
- [x] Проверки в эмуляторе: экран включён/выключен, средняя кнопка,
      сочетание с правой, DPI-клик, длительное удержание.
- [x] Локальный HUB собирается и готовит проверяемый офлайн-патч.
- [x] Независимая проверка ресурса: четыре изменённых байта с CRC,
      все 3939 непустых CRC-блоков верны; код обновлятора не менялся.

## Текущее состояние мыши

Шестая кнопка: обычная «0», профиль 1. Колёсику после сравнительного теста
возвращено стандартное действие. Общая задержка осталась исходной, 8 мс.
Кандидат исправленной прошивки подготовлен только локально и **не установлен**.
Сохранённые дисковые профили старого HUB содержат прежнее назначение прокрутки:
не запускать старый HUB до синхронизации, чтобы не затереть тестовую настройку.
