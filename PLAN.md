# FURYCUBE G9 PRO HUB — цели и состояние

Требование пользователя: самостоятельный HUB, шестая кнопка работает сразу
независимо от OLED; картинки и виджеты на маленьком экране; публичный GitHub
с понятным README. Физическая кнопка должна работать после закрытия программы.
Макросы проверяются после обычной «0».

## Следующий обязательный шаг

Пользователь уточнил: перенесены не все настройки старого HUB. Каталог назначений
не заменяет DPI, параметры сенсора/питания, библиотеку профилей и редактор макросов.
Сверка G9/ms_1 и перенос пропущенных настроек выполнены в коде; чтение полного
блока и восстановление одного таймера проверены на wired-мыши. Проверки других
параметров на устройстве и реальная загрузка макросов остаются отдельными этапами.

FCC ID на нижней наклейке **отсутствует** (подтверждено пользователем). Повторно
запрашивать его не нужно; сам FCC ID не является обязательным условием. Для
установки прошивки нужен подтверждённый путь восстановления всех затронутых
данных: полный образ либо независимо доступный откат приложения с сохранением
остальной памяти. Пользователь выбрал разборку перед поддержкой и
прислал новые фото своей платы: **BK3633QN48, EPC-V18U0002, 2025-4-3**.
Первые два фото он отозвал как другую мышь; их не использовать как данные
экземпляра. Программный OL3 опубликован, прошивка не установлена.

Экспериментальный код и прошивка подготовлены для проверки, но в мышь не установлены.
Результаты эмуляции не заменяют проверку реальной кнопки, изображения, сна,
восстановления штатного экрана и аппаратного макроса. Цель целиком не достигнута.

## Уточнение пользователя: работа по частям, физические проверки после сна

До возвращения пользователя продолжаются самостоятельная разработка, офлайн-
проверки, безопасное чтение устройства и публикация собственных исходников.
Не требуется держать пользователя у компьютера или ждать его для этих этапов.

Утренняя проверка **без перепрошивки**:

1. FCC ID отсутствует; чип и маркировка платы уже прочитаны по новым фото.
   Следующая аппаратная задача — установить выводы доступа/сброса и безопасное
   чтение. Назначения контактов пока не определены, ничего не подключать наугад.
2. Открыть `Run-Hub.cmd`, на первой вкладке прочитать назначения из мыши.
3. Проверить выбор любой кнопки, категорий, клавиш/модификаторов и параметров.
4. Во второй вкладке выбрать картинку/виджет, двигать рамку и менять её размеры
   ползунками; положение и размер должны меняться независимо.
5. Проверить сохранение/открытие проекта и автосохранение после закрытия окна.
6. На вкладке устройства кнопка «Данные мыши» показывает пассивно полученные
   данные. Заряд уже проверен; для уровня DPI нужен новый физический DPI-клик.

Обычная клавиша на экранной кнопке и изображение на OLED **ещё не исправлены
в самой мыши**: прошивка оставлена исходной до выполнения условия восстановления.
Кнопка «На OLED» на ней должна отказать без отправки изображения.

**Обязательное условие: всё должно быть восстановимо.** Перепрошивка запрещена
до подтверждённого пути восстановления. Официальный образ 1.08 пригоден как
исходник штатного приложения, но один файл не доказывает доступность загрузчика
при неисправном приложении и сохранность остальной памяти. Не предлагать
рискованную установку вместо подготовки восстановления.
