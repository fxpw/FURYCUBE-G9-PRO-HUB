**Следующая попытка после подтверждённого сброса:** отдельный клиент остановился
уже на первом GET0B/selector1 — 0 фрагментов картинки. Повторная зелёная проверка

сценариев stock/OL7 подтвердили другой заголовок ответа и отсутствие NVM-записей
на валидных профилях; общий код всё равно перечитывает активный профиль после
копирования ответа. Это гипотеза для чтения, не доказанное исправление радио.
После подтверждённого сброса эта проба тоже дала тайм-аут. Далее по USB
установлены диагностические DG1/DG2; актуальное состояние приведено выше.

1. Довести новый радио-OLED обработчик и отдельный защищённый клиент, проверить
   пакет обновления; сохранить ввод и профиль 1 / 1600 DPI / 1000 Гц / шестая «0».
2. Установить проверенный пакет по USB и подтвердить один видимый кадр по 2.4G
   одновременно с рабочими движением, кликами и клавишей.
3. После успешной радиопередачи включить её в HUB и автоматически отправлять
   последний полный кадр при USB↔2.4G, переподключении и запуске HUB.
4. Проверить виджеты и автозапуск. Затем отдельно разбирать удержание кадра
   через перезапуск без HUB. Макросы отложены.

Не завершать этот этап только отчётом об офлайн-модели: физический результат
остаётся критерием выполнения. Запрос пользователю нужен при готовности к
конкретному подключению или визуальной проверке, остальную работу продолжать.

Требование пользователя: самостоятельный HUB, шестая кнопка работает сразу
независимо от OLED; картинки и виджеты на маленьком экране; публичный GitHub
с понятным README. Физическая кнопка должна работать после закрытия программы.
Обычная клавиша уже проверена; по последнему уточнению пользователя макросы
отложены, текущий приоритет — физический OLED, картинки и виджеты.

## Новые обязательные требования пользователя — ещё не выполнены

**Проводной ввод после OL6:** пользователь уточнил — USB-клавиша «0» работает,
пропадают только движение и клики; по радио всё работает. Перезапуск только

что движения/кликов всё ещё нет. На инструкциях воспроизведён отдельный дефект:

пользователь увидел лишь краткое движение; USB-ввод не подтверждён, в журнале
за этот интервал есть только mouse-источник FA60. Возвращены шестая «0» и
1600 DPI (выбранная ступень во время проверки стала 5); все 117 байт снова
совпали с резервной копией. Позже пользователь вручную перезагрузил Windows
